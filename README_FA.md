# اُبلیویون - کارگیر غیررسمی Warp

«اینترنت، برای همه، یا هیچ‌کس!»

اُبلیویون دسترسی امن و بهینه به اینترنت را از طریق برنامه‌ای ساده و کاربرپسند
با فناوری Cloudflare Warp فراهم می‌کند.

این برنامه بر پایهٔ [Aether](https://github.com/CluvexStudio/Aether) ساخته شده
است؛ هستهٔ Warp نوشته‌شده به زبان Rust که با پروتکل‌های MASQUE و WireGuard سخن
می‌گوید و از یک پایهٔ کد واحد روی اندروید، ویندوز و لینوکس اجرا می‌شود.

> **English docs:** the English version of this document is available in
> [README.md](README.md).

![oblivion3.jpg](media/oblivion3.jpg)

## امکانات

- **دو گونه انتقال**: MASQUE روی QUIC/HTTP-3 یا HTTP/2، و WireGuard کلاسیک.
- **Zero Trust**: اتصال به‌عنوان دستگاه مدیریت‌شده روی حساب سازمانی Cloudflare
  سازمان شما، با ورود توسط کد ایمیل‌شده، توکن سرویس، یا توکنی که خود دارید.
- **قانون‌های ترافیک**: مقصدی را کامل مسدود کنید، یا آن را بیرون از تونل مستقیم
  بفرستید؛ همان چیزی که برنامه‌های بانکی و سایت‌های داخلی به آن نیاز دارند.
- **تونل تفکیکی**: انتخاب کنید کدام برنامه‌های اندروید بیرون از تونل بمانند.
- **پنهان‌سازی (Obfuscation)**: نمایه‌هایی که دست‌دهی اولیه را برای شبکه‌هایی که
  آن را انگشت‌نگاری می‌کنند بازسازی می‌کنند.
- **کاربرپسند**: رابطی ساده و روشن به دو زبان فارسی و انگلیسی، با چیدمان کامل
  راست‌به‌چپ هر جا که فارسی انتخاب شود.
- **دسکتاپ بومی**: کارگیر دسکتاپ ویندوز با همان زبان طراحی نسخهٔ موبایل؛
  یکپارچه با نوار اعلان سیستم، پنجرهٔ جمع‌وجور، پوستهٔ تاریک و روشن، و هلپر
  دارای دسترسی بالا همراه برای حالت تونل کامل.

## شروع سریع

1. **بارگیری**: نسخهٔ سکوی خود را از صفحهٔ
   [انتشارها](https://github.com/bepass-org/oblivion/releases) بردارید و نصب کنید.

2. **اتصال**: اُبلیویون را باز کنید و کلید اتصال را بزنید.

روی اندروید برنامه به‌صورت سرویس VPN اجرا می‌شود و به root نیاز ندارد. روی
ویندوز و لینوکس یک پروکسی SOCKS5 محلی در اختیار می‌گذارد و مسیریابی کامل دستگاه
به دسترسی مدیر (administrator) نیاز دارد.

## دسکتاپ ویندوز

کارگیر ویندوز یک برنامهٔ دسکتاپ بومی است که از همان پایهٔ کد Flutter و همان
زبان طراحی نسخهٔ موبایل ساخته شده است: نشان‌وارهٔ کهربایی، فهرست‌های کارتی گرد،
کلید واحد اتصال و قلم Vazirmatn میان هر دو مشترک است، تا برنامهٔ دسکتاپ همچون
خواهر و برادری رسمی برای نسخهٔ گوشی به نظر برسد.

### آنچه در بستهٔ ویندوز همراه است

همهٔ نیازهای برنامه کنار `oblivion.exe` بسته‌بندی شده‌اند؛ نیازی به نصب جداگانهٔ
ران‌تایم، کتابخانه یا ابزار توسعه نیست:

| جزء | نقش |
| --- | --- |
| `oblivion.exe` | خود برنامهٔ دسکتاپ |
| `oblivion_core.dll` | پل FFI که موتورهای تونل را سرپرستی می‌کند |
| `aether.exe` | هستهٔ Aether Warp (MASQUE / WireGuard / gool) |
| `psiphon.exe` | موتور سایفون، برای هسته‌های سایفون و زنجیره |
| `oblivion-helper.exe` | هلپر دارای دسترسی بالا برای پیکربندی مسیریابی تونل کامل |
| `hev-socks5-tunnel.exe`، `wintun.dll` | دستگاه tun که حالت تونل کامل از آن استفاده می‌کند |
| `flutter_windows.dll`، `data\` | موتور Flutter و دارایی‌های برنامه |

### دریافت برنامه

- **نصب‌کننده** - `Oblivion-Setup-x64.exe` را اجرا کنید، اعلان‌ها را بپذیرید؛
  اُبلیویون در منوی استارت (و به‌دلخواه روی میزکار) پدیدار می‌شود. نصب‌کننده در
  صورت نیاز، ران‌تایم Microsoft Visual C++ را بی‌صدا اضافه می‌کند.
- **نسخهٔ قابل‌حمل** - `Oblivion-Windows-x64.zip` را هر جا که می‌خواهید باز کنید
  و `oblivion.exe` را مستقیم از همان پوشه اجرا کنید؛ این بایگانی یک رونوشت
  محلی از ران‌تایم C را همراه دارد، پس روی دستگاه‌های بدون هیچ بستهٔ
  redistributable نیز کار می‌کند.

### رفتار دسکتاپ

- پنجره در آغاز، مرکز صفحه و با همان قاب گوشی‌مانندی که طراحی برای آن کشیده
  شده باز می‌شود و تا یک پنل جمع‌وجور نیز قابل تغییر اندازه است؛ بستن پنجره
  برنامه را به‌جای خروج، به سینی سیستم می‌برد.
- نقش سینی، مرحلهٔ تونل (بی‌کار، در حال اتصال، متصل) را با نمادی جداگانه برای
  هر مرحله نشان می‌دهد و منوی آن - نمایش، پنهان‌سازی، خروج - به زبان فعال برنامه
  ترجمه شده است.
- **زبان**: تنظیمات › زبان میان انگلیسی و فارسی جابه‌جا می‌شود. فارسی کاملاً
  راست‌به‌چپ چیده می‌شود: همهٔ ردیف‌ها، سربرگ‌ها، انتخابگرها و گفتگوها قرینه
  می‌شوند، در حالی که نشانی‌ها، نقطه‌پایان‌ها و IPها چپ‌به‌راست می‌مانند.
- **پوسته**: تنظیمات › پوسته از سیستم پیروی می‌کند، یا تاریک و روشن را تحمیل
  می‌کند.
- **مسیریابی**: تنظیمات › حالت مسیریابی سه گزینهٔ *فقط پروکسی محلی*، *پروکسی
  سیستم* و *تونل کامل* را پیشنهاد می‌دهد. تونل کامل همهٔ ترافیک دستگاه را از
  wintun می‌گذراند و هنگام شروع دسترسی مدیر می‌خواهد؛ بدون آن، برنامه روی پروکسی
  می‌ماند و همین را در صفحهٔ اصلی یادآور می‌شود.

### ساخت برنامهٔ ویندوز توسط خودتان

روی دستگاه ویندوزی که Flutter 3.44 به‌بالا، Rust و Go نصب دارد:

```sh
git clone --recursive https://github.com/bepass-org/oblivion.git
cd oblivion
flutter pub get
flutter build windows --release
```

بستهٔ انتشار در `build\windows\x64\runner\Release` ساخته می‌شود. برای پیچیدن آن
در نصب‌کنندهٔ تک‌فایل، [Inno Setup](https://jrsoftware.org/isinfo.php) را نصب
کنید و اسکریپت همراه را کامپایل کنید:

```sh
iscc windows\installer\oblivion.iss
```

اسکریپت، بستهٔ انتشار را می‌خواند، نقش و اطلاعات نسخه را در آن می‌نشاند و
`dist\Oblivion-Setup-x64.exe` را می‌نویسد.

## ساخت پروژه

### پیش‌نیازها

- Flutter 3.44 یا تازه‌تر
- Rust (پایدار) برای هستهٔ Aether و پل FFI
- Go، برای موتور سایفون
- Android NDK r27 یا تازه‌تر، و JDK 17، برای ساخت اندروید
- CMake، Ninja، Clang و `libgtk-3-dev` برای ساخت لینوکس
- میزبان ویندوز، NASM و MSYS2 برای ساخت ویندوز (NASM بورینگ‌اس‌اس‌ال را می‌سازد
  و MSYS2 هلپر hev-socks5-tunnel را)

### کلون‌کردن با زیرماژول‌ها

هستهٔ Aether و hev-socks5-tunnel در مخزن‌های جداگانه‌ای زندگی می‌کنند و به‌صورت
زیرماژول به اینجا پیوند خورده‌اند، پس بازگشتی کلون کنید:

```sh
git clone --recursive https://github.com/bepass-org/oblivion.git
```

اگر پیش‌تر بدون `--recursive` کلون کرده‌اید:

```sh
git submodule update --init --recursive
```

### ساخت

```sh
flutter pub get

flutter build apk --release --split-per-abi
flutter build apk --release
flutter build linux --release
flutter build windows --release
```

ساخت اندروید هستهٔ Aether را برای هر ABI همان‌جا کامپایل متقاطع می‌کند، پس نخستین
ساخت زمان‌بر است. برای ساخت تنها یک ABI، `--target-platform android-arm64` را
بیفزایید.

APKهای انتشار زمانی که `android/key.properties` موجود باشد امضا می‌شوند و در
غیر این صورت به کلید اشکال‌زدایی بازمی‌گردند.

  استفاده می‌کنیم.

### Aether

- **پروژه**: Aether
- **مخزن گیت‌هاب**: [Aether در گیت‌هاب](https://github.com/CluvexStudio/Aether)
- **پروانه**: [GNU Affero General Public License v3.0](https://github.com/CluvexStudio/Aether/blob/main/LICENSE)
- **توضیح**: Aether هستهٔ Warp است که این برنامه بر آن ساخته شده. MASQUE روی QUIC
  و HTTP/2، WireGuard، کشف نقطه‌پایان، پنهان‌سازی و ثبت‌نام Cloudflare Zero Trust
  را پیاده‌سازی می‌کند و تونل را به‌صورت یک پروکسی محلی در اختیار می‌گذارد.

- **پروژه**: quiche

- **توضیح**: پیاده‌سازی QUIC و HTTP/3 ابرفلاودر. Aether تونل MASQUE را با آن حمل
  می‌کند.

### hev-socks5-tunnel

- **پروژه**: hev-socks5-tunnel
- **مخزن گیت‌هاب**: [hev-socks5-tunnel در گیت‌هاب](https://github.com/heiher/hev-socks5-tunnel)
- **پروانه**: [MIT](https://github.com/heiher/hev-socks5-tunnel/blob/master/LICENSE)
- **توضیح**: یک forwarded از tun به socks5. روی اندروید بسته‌های رابط VPN را به
  اتصال‌های پروکسی تبدیل می‌کند که هسته حمل‌شان می‌کند. روی ویندوز رابط wintun را
  به پروکسی محلی می‌خوراند.

### BoringTun

- **پروژه**: BoringTun
- **مخزن گیت‌هاب**: [BoringTun در گیت‌هاب](https://github.com/cloudflare/boringtun)
- **پروانه**: [BSD 3-Clause](https://github.com/cloudflare/boringtun/blob/master/LICENSE)
- **توضیح**: پیاده‌سازی WireGuard در فضای کاربر به زبان Rust، که برای انتقال
  WireGuard به کار می‌رود.

در نظر داشته باشید که استفاده از این ابزارها تابع پروانه‌های خود آن‌هاست و
باید شرایط آن پروانه‌ها را مطالعه کنید.
